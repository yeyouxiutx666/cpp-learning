### 指针  
指针指向数据的地址，指针也是一种数据类型，在32位操作系统下占4字节，在64位操作系统下占8字节，指针记录地址  
#### 定义指针

### 内存分区模型  
#### 代码区  
代码区存放函数体的二进制代码，由操作系统进行管理  
#### 全局区  
全局区存放全局变量和静态变量和常量  
#### 栈区  
栈区由编译器自动分配和释放，存放函数的参数值，局部变量等  
#### 堆区  
由程序员分配和释放，若程序员不释放，在程序结束时由操作系统回收   
#### tip  
内存四区不同区域存放的数据赋予不同的生命周期，使更灵活的编程  
在未执行程序前就存在代码区和全局区  
### 代码区  
存放cpu执行的机器指令，代码区是共享的，只读的  
共享的意思即为对于频繁使用的程序，代码在内存中只有一份，不会重复存储  
只读防止代码被修改  
### 全局区  
全局区包含常量区，字符串常量，其他常量，该区域数据由操作系统在程序执行后释放  
#### 静态变量  
static 数据类型 变量名 = 值，也存放在全局区  
#### 常量分类  
常量分为字符串常量和const修饰的常量  
cout << (int)&"hello world" ;  //字符串属于常量  
const修饰的常量分为const修饰的全局变量和局部变量  
const修饰的局部变量，即局部常量和局部变量不在全局区  

### 栈区  
由编译器自动分配和释放，存放函数的参数值，局部变量等  
注意事项：不要返回局部变量的地址，栈区开辟的数据由编译器自动释放  
eg:  
int * func ()  
{  
      int a = 10 ;  //局部变量，存放在栈区，栈区的数据在函数执行完成后自动释放  
      return &a ;  
};  
int main ()  
{  
      int *p = func () ;  
      cout << *p << endl;  //第一次maybe打印成功，因为编译器会做保留  
      cout << *p << endl;  //不会正常输出a的值  
};  
#### 形参的数据也会存放在栈区  

### 堆区  
由程序员分配释放，若程序员不释放，在程序结束时由操作系统回收  
在c++中主要利用new()在堆区开辟内存  
int *p func()  
{  
      //利用new将数据开辟到堆区  
      int *p = new int(10); //new返回的就是地址，所以不用取址符，也可以写其他数据，例如string("hello");  
      return p;  
      //指针本质也是局部变量，放在栈上，指针保存的数据放在堆区  
};  
#### new操作符  
释放操作符 delete // delete p;  

#### 在堆区开辟数组  
创建10整型的数组在堆区

### 函数提高  
#### 函数默认参数  
在c++中，函数的形参列表的形参可以有默认值  
语法：返回值类型 函数名 (参数 = 默认值) {};  
注意事项：  
1.某个位置已经有了参数的默认值，从此之后的参数都必须有默认值，即默认参数写在其他参数之后  
2.函数在声明和实现的时候，默认参数选其一，即使默认参数的值都一样，一个写了默认值，另一个只写参数不写默认值  
void func(int a = 10);void func (int a){};  
#### 占位参数  
返回值类型 函数名 (数据类型);  
也可以有默认参数  
返回值类型 函数名 (数据类型 = 值);  
调用函数的时候需要填补占位参数，即需要在调用时写入占位参数的值  
#### 函数重载  
函数名可以重复，提高复用性  
函数重载满足条件  
1.同一个作用域下  
2.函数名相同  
3.函数参数类型不同或个数不同或顺序不同  
注意事项：函数的返回值不同不可以作为函数重载的条件  
#### 函数重载的注意事项  
1.引用作为重载的条件  
void func (int &a);  
void func (const int &a);  
运行func(a);会调用第一个函数，func(10);会调用第二个函数  
2.函数重载碰到默认参数  
如果除了参入的参数外，其他参数有默认值，会不知道调用哪个函数，报错
